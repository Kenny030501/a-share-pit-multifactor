# A股 Point-in-Time 多因子量化回测框架 — 项目总结报告

> 作者：达鸿儒　｜　完成日期：2026-07　｜　语言/工具：Python（pandas / NumPy / SciPy / cvxpy）、SQLite、AkShare
> 代码规模：约 6,300 行 Python，覆盖数据、回测、因子诊断、稳健统计、容量分析、组合优化、样本外验证七大模块

---

## 一、一句话概括

从零搭建了一套**按保守可用日规则运行的 A 股全市场多因子选股回测框架**，并对国泰君安「短周期价量四因子」方法进行方向性复现。项目得到一个诚实但反直觉的结果：**传统基本面策略在本样本和基准口径下没有稳定超额；短周期日频价量策略值得继续检验，但仍不能被表述为已确认的 alpha。**

---

## 二、干了什么（工作内容）

| 模块 | 做了什么 |
|------|---------|
| 数据地基 | 用免费数据源 AkShare 拉全市场 5,527 只 A 股的后复权日线、财报、TTM 估值，落地为 JSON 缓存并导入 SQLite（1,254 万行价格数据、5 张表、约 1.6 GB） |
| 回测引擎 | 滚动 point-in-time 回测：每个再平衡日只使用不晚于保守可用日的数据选股，前向持有，报告超额收益、换手与交易摩擦 |
| 因子诊断 | 对每个因子算 IC/IR、五分组分层回测、行业中性前后对比，并加入 Newey-West、移动区块 bootstrap 与 BH-FDR 多重检验 |
| 组合优化 | 用 cvxpy 做行业中性 + 规模中性 + 换手约束下的最大化 alpha 组合优化，对齐研报口径 |
| 样本外验证 | 锚定扩张窗口的 walk-forward 检验，记录训练至测试的泛化缺口，专门识别「样本内 Sharpe 最高就选它」的过拟合陷阱 |
| 容量压力 | 支持按组合 AUM、63 日 ADV 和 63 日波动率估算参与率与平方根市场冲击；该结果是压力模型，不冒充真实成交滑点 |
| 研报复现 | 方向性复现国泰君安短周期价量四因子，2012–2017、728 期截面、T+2 调仓 |

## 三、创造了什么价值

1. **一套可复用、可复现的研究基础设施。** 统一数据入口 `load_market_snapshot()` 一次离线秒级加载全市场数据；全市场 5 套策略、无摩擦+真实两版回测可在约 234 秒内离线跑完。任何新因子、新策略都能挂上去直接测。

2. **把「看起来赚钱」和「真的赚钱」区分开。** 框架强制做三件行业里常被省略的事：真实交易成本、正确基准、样本外检验。得出的结论经得起面试官逐条追问。

3. **一个可讲的诚实结论。** 传统 6 因子相对全 A 等权基准的真实超额全部为 **−10% ~ −12%**。固定 `reversal_lottery` 参考在合并测试窗中的超额为 **+5.62%/年（Sharpe 0.87）**，但若规格不是在测试窗前冻结，它只能作为描述性参考，不能被称为无偏样本外证据。

4. **国君四因子方向性复现。** 全市场 T+2 IC 诊断中四因子全部正 IC、分层单调；在近似股票池、风险模型和交易口径下，行业/规模中性且带换手约束的版本对标中证 500 代理取得净超额 **+1.22%/年**。这不是对原研报全部设定的等价复刻。

## 四、解决了什么问题

**核心问题：怎么降低回测「偷看未来」的风险。** 这是量化回测最容易翻车、也最难自证清白的地方。三处针对性设计：

- **财务数据前视：** AkShare 的「最新公告日期」字段在本数据中不可靠，因此改用**法定披露截止日**推算保守可用日——年报到次年 4-30 才允许使用，回测每天只取「可用日 ≤ 当天」的最新财报。它避免提前使用，但并不等于掌握了逐份公告的真实发布时间。
- **基准选错导致高估 alpha：** 策略偏小盘、等权，若拿大盘市值加权的沪深 300 当基准，会把「小盘溢价 + 等权溢价」误算成选股能力。改用与策略同口径的**通达信全 A 等权指数（880008）**，且其日线日期直接作为交易日历，组合与基准逐日强制对齐。
- **过拟合自欺：** 用锚定扩张 walk-forward，训练窗选策略、测试窗拼接。结果暴露：三折训练窗都选中样本内 Sharpe 最高的策略，但它样本外超额 −4.21%——**样本内越碾压，越是过拟合信号。**

## 五、遇到了什么难点

| 难点 | 症状 | 解决 |
|------|------|------|
| **组合在换手约束下塌缩** | 线性目标 + 换手约束时，优化解「棘轮式」坍缩到个位数持仓，组合完全不分散 | 目标函数加 L2 ridge 风险近似强制分散；带换手约束走 cvxpy/CLARABEL，不可行时回退全额中性重建 |
| **交易成本吃光超额** | 国君四因子 T+2 短周期调仓，不控换手时累计成本拖累达 122%，净超额 −15.88% | 加严格换手约束（单期 ≤ 0.15），成本降到 40%，净超额转正 +1.22%/年——**换手约束是 T+2 存活的关键** |
| **全市场盯市太慢被后台杀掉** | 每个交易日对全市场 5,527 只做线性盯市 ≈ 147 亿次比较，单套策略要跑十几分钟，常因超时被杀 | 改为只对持仓约 100 只、二分定位收盘价；数值与优化前逐位一致，速度提升到分钟级 |
| **PIT 总市值没有现成数据** | 合成中证 500 和规模中性都需要历史时点总市值，免费源没有 | 用「净利润/EPS」近似总股本 × 现价快照锚定的不复权价，横截面误差多在几个百分点，够用 |
| **缓存静默重复联网** | `load_hfq_prices` 的缓存 key 含「今天」日期，换一天就 cache miss 静默联网重抓 | 统一走 `load_market_snapshot` 按文件 glob 定位、取最宽序列，规避此坑 |

## 六、已知局限（诚实披露）

- **残余幸存者偏差：** 基准端无幸存偏差，但策略选股池仍是「当前全 A」名单（不含退市股），会**高估**策略。彻底根治需引入历史时点成分股 + 退市股数据。
- **主复现范围有限：** 交易组合只使用 4 个代表性短周期价量因子；代码实现了 187 个 GTJA191 名称，旧筛选中仅 70 个满足至少 10 期有效 IC。大规模筛选必须配合多重检验与独立测试窗，不能直接按样本内 IC 挑选。
- **风险模型简化：** 用 L2 ridge 代替完整协方差风险模型（BARRA CNE5 列为后续）。
- **合成中证 500 ≠ 官方成分：** 用市值规则近似，非指数委员会逐案调入调出（但成员判定 PIT 干净、无 membership 前视）。
- **容量模型待校准：** 平方根冲击只用于 AUM 压力测试；没有订单级成交与滑点数据时，不把模型输出当作实盘容量结论。
- **旧结果统计口径：** 已提交的 IC JSON 早于稳健统计模块，只能用独立期近似审计；新运行会直接输出 Newey-West、移动区块 bootstrap 和 BH-FDR。

## 七、这个项目证明了什么能力

- **端到端独立完成**一个可复现的量化研究系统：数据工程 → 回测引擎 → 因子检验 → 组合优化 → 样本外验证。
- **对「数据陷阱」有系统性认知**：前视偏差、基准偏差、幸存者偏差、过拟合，逐一识别并给出工程化解法。
- **诚实的研究态度**：不粉饰负超额，主动披露局限，把「证伪」当作有价值的结论。
- **研究统计能力**：处理 IC 序列相关、多重检验和区块抽样，不以未经校正的 t 值筛选大量因子。
- **交易执行意识**：显式记录单边换手、ADV 参与率、显式成本和 AUM 相关市场冲击。
